### 🏗️ The Ecosystem

We are architecting a system where humans define the "Grid" (Structure & Intent), and Agents travel the "Lanes" (Execution) autonomously within safe boundaries.

#### 1. Visibility & Telemetry
Before we can trust agents to drive themselves, we need a dashboard.

> **📦 [agtrace](https://github.com/lanegrid/agtrace)**
> **The Vital Monitor for AI Coding Agents.**
> A TUI tool to visualize "Context Window Anxiety" and execution timelines in real-time.
>
> [![crates.io](https://img.shields.io/crates/v/agtrace.svg?style=flat-square)](https://crates.io/crates/agtrace)
> [![npm](https://img.shields.io/npm/v/@lanegrid/agtrace.svg?style=flat-square)](https://www.npmjs.com/package/@lanegrid/agtrace)

#### 2. Workflow & Automation
Agents need structured, type-safe workflows to operate reliably.

> **📦 [git-workflow](https://github.com/lanegrid/git-workflow)**
> **Type-safe Git Workflow for Agentic Development.**
> A CLI tool (`gw`) providing worktree-aware git operations with GitHub integration and smart next-action suggestions.
>
> [![crates.io](https://img.shields.io/crates/v/git-workflow.svg?style=flat-square)](https://crates.io/crates/git-workflow)

### 🧭 Our Philosophy

* **Structure brings Freedom:**
    Agents perform best not when given infinite freedom, but when operating within clear, structured environments (SSOT).
* **Zero-Overhead & Local:**
    Our tools are built in **Rust**. They run locally, respect your privacy, and consume minimal resources. We believe developer tools should be invisible until needed.
* **Human-in-the-Loop, Optimized:**
    We design workflows to conserve the scarcest resource in software development: **Human Attention**.
